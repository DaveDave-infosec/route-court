Your agent picked a route. Was it the one you asked for?

You pay an agent a small fee to move your money across chains. It asks LI.FI for every route and commits to one. If you think it broke your instructions, a court checks the choice against the routes that really existed at that moment, and the fee goes to whoever is right.

How a dispute runs

Nothing waits on the happy path: if nobody disputes, the agent is paid. The court only runs when the user objects.

  1. LI.FI

    The agent asks for routes

    One call returns every route with bridges, fees, timing and hops. The agent commits to one.

  2. Repository

    The choice is frozen

    The full response, the mandate and the pick are saved and hashed. Code computes cost, time and hops for every route.

  3. Internet Court, Base Sepolia

    The fee goes into escrow

    The user opens an agreement with the agent. The 5 USDC fee sits in it until the case ends.

  4. Internet Court, Base Sepolia

    The user disputes

    The user says the route broke the mandate. Both sides argue from the same hashed snapshot.

  5. GenLayer

    The jury rules

    Validators each judge the case on their own and must agree. They decide what "sensible" and "overpay" mean here.

  6. Internet Court, Base Sepolia

    The fee moves

    The agreement settles to the side the jury ruled for, and that side claims the 5 USDC.

Why the jury is our own GenLayer contract

Internet Court's relay has not delivered a GenLayer verdict on Base Sepolia since 19 March 2026. So the judge is a GenVM v0.4 contract on GenLayer Studio Next, and the side it rules for carries the ruling to the agreement: only that side submits evidence, quoting the GenLayer transaction, and the agreement settles by default to it.

A trap other builders should know

If both parties submit evidence while the relay is down, the agreement moves to a resolving state that only the relay can end. There is no timeout, so the escrow stays locked. Route Court never lets both sides submit until the relay is back.

Check it yourself

Clone the repository and run npm install. None of the first two steps needs a wallet.

Watch an agent pick

Live LI.FI routes, facts, the pick, the hash and the exact evidence the court would read.

npm run dry-run -- --mode preferred

Verify both cases

Reads Base Sepolia and GenLayer, recomputes each snapshot hash and checks both verdicts match.

npm run verify -- --case B

Replay a whole case

With a little Base Sepolia ETH: escrow, dispute, jury, settlement, claim. About 20 minutes.

npm run demo -- --case B
